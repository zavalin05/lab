# Лабораторная работа 2 (Задача 4)
## Умножение матриц

### Сборка
```bash
gcc zadanie_4.cpp -o zadanie_4 -fopenmp
```

### Запуск
```bash
zadanie_4.exe <rowsA> <n> <colsB>
```

### Пример:
```bash
zadanie_4.exe 1000 500 1000
```

### Где:
- `rowsA` — число строк матрицы A
- `n` — общее измерение (столбцы A = строки B)
- `colsB` — число столбцов матрицы B
- число потоков вводится с клавиатуры после запуска

Программа перемножает матрицы A (rowsA × n) и B (n × colsB), сравнивая время выполнения на 1, 2, 4, 8 потоках.

### Сравнение времени на разном числе потоков:

```bash
zadanie_4.exe 1000 500 1000   # ввести 1
zadanie_4.exe 1000 500 1000   # ввести 2
zadanie_4.exe 1000 500 1000   # ввести 4
zadanie_4.exe 1000 500 1000   # ввести 8
```
